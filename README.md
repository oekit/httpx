```bash
go get github.com/oekit/httpx@v0.1.5
```

## 这个仓库做什么

`httpx` 是基于 Hertz Client 的**高级 HTTP 客户端**：把服务发现、熔断、重试、指标、
链路透传这些“每次都要手写一遍”的东西变成构造选项。

## 核心能力

- `WithNNS`：对接 NNS 服务发现（实例列表自动刷新）
- `WithCircuitBreaker`：熔断（per-service，错误可判定 `ErrCircuitOpen`）
- `WithRetryConfig`：指数退避 + 抖动重试（Hertz 官方引擎，连接池感知）
- `WithMetrics`：Prometheus 弹性指标（熔断/重试计数）
- `WithTracePropagation`：OTel 链路透传
- 实例权重贯通：注册中心的权重配置真实生效于负载均衡

## 快速使用

```go
import "github.com/oekit/httpx/httpx"

c := httpx.NewClient("payment-svc", httpx.WithTimeout(5*time.Second))
var out Result
err := c.GetJSON(ctx, "/api/v1/pay", &out)
```

## 边界

- 轻量 WebSocket/NATS 等不经过服务发现的场景 → [network](https://github.com/oekit/network)
- 服务治理语义（实例缓存/多级降级）在 [nns](https://github.com/oekit/nns)
